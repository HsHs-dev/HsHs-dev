# Systems Lab GitHub Profile — setup

All SVG assets are yours, stored locally in the GitHub profile repository. They do not depend on live third-party stats hosts.

## Install

1. Copy the contents of this folder into your GitHub profile repository: `HsHs-dev/HsHs-dev` (the README.md plus `assets/`, `scripts/`, and `.github/workflows/systems-lab.yml`). Preserve the folder structure. The image files are already generated.
2. Commit and push to your default branch.
3. Open https://github.com/HsHs-dev/HsHs-dev/actions and select **Refresh Systems Lab activity** → **Run workflow** (default branch).
4. When the workflow succeeds, it replaces the placeholder `assets/activity.{dark,light}.svg` with real public metrics and refreshes them once per day.

GitHub Actions → General → Workflow permissions may need to be set to **Read and write permissions**, if GitHub rejects the generated SVG commit. The workflow requests `contents: write`, but organization/repository policies can restrict it.

## Important

- The old `.github/workflows/profile-cards.yml` from the previous profile design is no longer needed; delete it if you no longer use its `overview` and `contributions` image cards.
- The public events graph shows **recent public GitHub events**, not a complete contribution history or an exact number of commits. GitHub limits the recent event feed; even after a successful run, the graph can underrepresent activity.
- The daily GitHub workflow stores finished SVGs in your own repository. Visitors fetch images from GitHub, not a community-hosted statistics endpoint.
- The first run requires an enabled Actions workflow and permission to commit files. No personal access token is necessary: the built-in `secrets.GITHUB_TOKEN` is used.
- SVG motion is subtle and optional. Animation support varies by the GitHub image pipeline/browser, so each graphic is designed to look good without animation. Users with reduced-motion preferences receive a static graphic.
- No JavaScript or external fonts are embedded into the artwork.

## Customize

- The header and diagram are generated by `python scripts/build_art.py` (requires Python 3, no dependencies).
- The activity dashboard is generated by `python scripts/update_activity.py` (requires internet and the public GitHub REST API).
- Preview the empty-state activity card without API access: `python scripts/update_activity.py --placeholder`.
- Change the GitHub username at the top of `scripts/update_activity.py` for another account.
- Colors and typography are editable near the start of each SVG generator function.
