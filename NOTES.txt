INSTALLATION
1. Copy README.md and merge assets/ and .github/ folders into HsHs-dev/HsHs-dev.
2. Keep your existing generated assets/overview.*.svg and assets/contributions.*.svg.
3. If you previously installed the old workbench card, remove the unused files:
     assets/workbench.dark.svg, assets/workbench.light.svg,
     scripts/render_workbench.py, data/workbench.json, data/last_public_push.json
   Only delete them if present. This is optional housekeeping.
4. Commit and push; the statistics workflow continues running as before.
5. Edit the 3 workbench bullets directly in README.md when your focus changes.

DESIGN
- 1 tiny transparent vector illustration with an animated cursor, code pulses,
  coffee steam, swaying leaves, and indicator light.
- No oversized panel or new API dependency.
- The redundant collapsible 'What I enjoy learning about' paragraph is removed.
- Other animated accents and theme-aware existing stats cards are unchanged.

NOTE: Some GitHub clients may suppress embedded SVG motion; a static picture remains usable.
